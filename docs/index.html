SideCursor

One keyboard, mouse and trackpad for your Mac and your Windows PC. Move the pointer off the edge of the Mac and it carries on across your Windows display. Encrypted, direct, no account.

Download for Mac Download for Windows View source

Free for noncommercial use · Mac: Apple Silicon, macOS 13+ · Windows: 64-bit Windows 10+

How it works

Install SideCursor on both computers. Your Mac keeps hold of the keyboard and mouse and passes them to Windows when the pointer crosses over.

1

Pair

Generate a pairing code on the Mac and paste it into the Windows app. Both sides use it to prove who they are.

2

Arrange your displays

Drag your Windows displays next to your Mac display, shown at real physical size. Shared edges turn green.

3

Cross the edge

Move the pointer through a green edge to enter Windows, and back through one to return to the Mac.

What you get

Multi-monitor crossing

The pointer leaves and enters at the same physical spot, even across several displays.

Clipboard that follows you

Copy text (up to 10 MB) or an image on one computer and paste it on the other.

Trackpad gestures

Three-finger swipes switch Windows desktops, open Task View or show the desktop. Pinch to zoom.

Smooth and fast

Unaccelerated 1:1 pointer movement, adjustable smoothing and scroll speed.

A panic key

Control + Option + F8 always stays on the Mac and takes control back at once.

Two connections

Direct over Tailscale, or a manual Bluetooth fallback when you have no network.

Built to be trusted with your keyboard

A tool that types for you has to be careful about who is allowed to send input.

  • Authenticated and encrypted. A shared pairing secret, X25519 key agreement and ChaCha20-Poly1305, with replay rejection.
  • Secrets stay in the system vault. The pairing secret lives in the macOS Keychain and Windows DPAPI, never on a command line or in a log.
  • No account, no cloud. The two computers talk directly to each other.
  • Always recoverable. A dropped connection, display change, lost permission or the panic key hands input back to the Mac and releases any held keys on Windows.
  • Open protocol. The wire format and test vectors are in the repository for anyone to check.

Install

The apps are not yet signed with a developer certificate, so each operating system asks you to confirm once.

Mac

Open the DMG and drag SideCursor into Applications. Right-click it, choose Open, then Open again. If macOS says it is damaged, run:

xattr -dr com.apple.quarantine /Applications/SideCursor.app

Then allow Device Control and Data Access (Accessibility) in System Settings → Privacy & Security.

Windows

Extract the zip anywhere and run SideCursor.Windows.exe. If SmartScreen appears, choose More info, then Run anyway.

Install Tailscale on both computers for the direct route, then follow the first-run steps in the README.

Good to know

Current limits
  • Input is captured on the Mac and sent to Windows. It does not work the other way around.
  • The Mac app is built for Apple Silicon. Intel Macs can build it from source, but that is untested.
  • Because the Mac app is ad-hoc signed, macOS may ask you to grant permissions again after an update.
  • Bluetooth is a manual fallback, not an automatic one.
